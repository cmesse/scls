# SCLS Build System - Project Context and Instructions

## Project Overview

I'm working on SCLS (Scientific Core Libraries Supercomputer), a repository of commonly used numerical libraries for HPC environments. The project provides pre-compiled, interdependent scientific computing packages for Enterprise Linux 9, with plans to support macOS via pkgutil.

**Website**: https://belfem.lbl.gov/scls.html  
**Current Release**: 2024, planning 2025 release with new YAML-based build system

## Current Implementation Status

### Completed Components

1. **Build Scripts**
   - `mac_builder.py` - Direct compilation for macOS without SPEC files
   - `rpm_builder.py` - Generates SPEC files from YAML for Linux RPM builds
   - `build_common.py` - Shared utilities for both builders
   - `build_order.py` - Flavor-aware dependency resolution

2. **Key Features Implemented**
   - Automatic version string handling (no quotes needed in YAML)
   - Verbose mode (`-v` flag) for real-time build output
   - Environment variable support in recipes (`configure: env:`)
   - Flavor-specific configure arguments
   - Platform-specific variable substitution (`%{sdk}`, `%{host}`, `%{prefix}`)
   - DESTDIR-based installation with file tracking
   - PKG creation for macOS with precise file lists

3. **Directory Structure**
   ```
   scls-build-system/
   ├── work/                    # Build artifacts (gitignored)
   │   ├── sources/            # Downloaded tarballs + patches
   │   ├── build/              # Build directories
   │   │   └── <package>/      # Simple package-specific dirs
   │   ├── pkgs/               # Built packages (RPMs/PKGs)
   │   ├── spkgs/              # Source packages
   │   └── specs/              # SPEC files (Linux only)
   ├── patches/                 # Version-controlled patches
   │   └── <package>/
   │       └── *.patch
   ├── recipes/                 # Package YAML configs
   ├── flavors/                 # Flavor YAML configs
   ├── templates/               # Jinja2 SPEC templates
   ├── descriptions/            # Package descriptions
   └── python/                  # Build scripts
   ```

## Flavors Configuration

- **gcc-debug** - gcc + reference BLAS/LAPACK + debug symbols
- **clang-debug** - clang + reference BLAS/LAPACK (faster C++ compilation)
- **gcc-mkl** - gcc + Intel MKL for production
- **intel-mkl** - Intel OneAPI compilers + OpenMPI + Intel MKL
- **gcc-mkl-cuda** - gcc + Intel MKL + CUDA support
- **macos** - clang/gfortran + Apple Accelerate framework

Each flavor installs to `/opt/scls/<flavor>/` (except macOS which uses `/opt/scls/`)

## Recipe YAML Structure

```yaml
name: package_name
version: 1.2.3  # No quotes needed - auto-converted to string
summary: Brief description
homepage: https://...
license: GPL-2.0-or-later

source:
  url: https://example.com/package-%{version}.tar.gz

# Optional - if absent, builds for all flavors
flavors:
  - gcc-debug
  - macos

requires:
  - dependency1
  - dependency2

features:
  fortran: true
  mpi: false
  openmp: true
  math: false

configure:
  type: autotools  # or cmake
  args:
    - --enable-shared
    - --disable-static
  # Flavor-specific args
  flavor_args:
    macos:
      - --disable-assembly
  # Environment variables
  env:
    VAR1: value
    M4: %{prefix}/bin/m4
  # Flavor-specific environment
  flavor_env:
    macos:
      SDK: %{sdk}
  optimization:
    O_level: 2
    strict_aliasing: false

build:
  parallel: true
  pre:
    - "echo 'Starting build'"
  post:
    - "echo 'Build complete'"

test:
  commands:
    - "make check 2>&1 | tee check.log"
  post:
    - "grep -E '^# (PASS|FAIL):' check.log || true"

install:
  post:
    - "rm -f %{prefix}/lib/*.la"
```

## Build Commands

### macOS
```bash
# Build, test, and install
python3 python/mac_builder.py -p gmp -v build test install

# Create PKG package
python3 python/mac_builder.py -p gmp pkg

# All steps
python3 python/mac_builder.py -p gmp -v build test install pkg
```

### Linux
```bash
# Generate SPEC only
python3 python/rpm_builder.py -p gmp -f gcc-debug --spec-only

# Full RPM build
python3 python/rpm_builder.py -p gmp -f gcc-debug -v
```

### Build Order
```bash
# All packages
python3 python/build_order.py recipes/

# Flavor-specific
python3 python/build_order.py recipes/ -f macos
```

## Key Implementation Details

### Version Handling
- Versions are automatically converted to strings in `load_yaml()`
- Works for: `version: 2.72`, `version: 1.4.20`, etc.

### Path Substitutions
- `%{prefix}` - Installation prefix (e.g., `/opt/scls`)
- `%{version}` - Package version
- `%{sdk}` - macOS SDK path (macOS only)
- `%{host}` - Host triple (e.g., `x86_64-apple-darwin22`)
- `%{buildroot}` - DESTDIR path (install phase only)

### Optimization Strategy
- Package-level optimization in recipe YAML
- Flavor adds architecture flags (`-march`) and debug symbols (`-g`)
- Compiler-specific flag translation handled automatically
- Always use `-fno-fast-math` for numerical safety

### MKL Integration (Future)

## macOS Specifics

### Build Tools Required
- System: Xcode Command Line Tools
- SCLS provides: m4, autoconf, automake, libtool, pkg-config, gfortran

### Installation
```bash
# Without sudo (builds to staging)
python3 python/mac_builder.py -p package build test

# With sudo (actual installation)
sudo python3 python/mac_builder.py -p package install

# PKG for distribution
python3 python/mac_builder.py -p package pkg
sudo installer -pkg work/pkgs/scls-package-version.pkg -target /
```

## Important Notes

- Always use OpenMPI (no MPICH, no Intel MPI)
- Work directory (`work/`) is gitignored - can delete to clean
- Patches go in `patches/<package>/` and are auto-copied to sources
- Test failures don't abort build (intentional for now)
- All output is real-time (no buffering issues)
- File tracking ensures clean PKG/RPM generation

## Design Philosophy

- **Simplicity over features** - One-person maintainable
- **Explicit configuration** - No hidden magic
- **Reproducible builds** - Same YAML → same output
- **Platform parity** - Same recipes work on Linux and macOS
- **Scientific correctness** - Never sacrifice accuracy for speed
