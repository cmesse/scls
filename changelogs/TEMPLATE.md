# Changelog Template for SCLS Packages

## Format Guidelines
- Use Markdown format with ## for version headers
- Include date in format: Day Mon DD YYYY
- Use bullet points (-) for changes
- Group changes by type: Added, Changed, Fixed, Removed

## Example:

## Version X.Y.Z - Day Mon DD YYYY
- Added: New feature description
- Changed: Modified behavior description  
- Fixed: Bug fix description
- Removed: Deprecated feature description

## Version X.Y.Z-1 - Day Mon DD YYYY
- Initial SCLS package release
- Built with optimization flags for [flavor]
- Includes patches for [platform] compatibility
