Scientific Core Libraries 2025 Repository

The Scientific Core Libraries repository is a collection of open-source numerical libraries. They are meant to be used on an Intel Core or Intel Xeon x86_64 Architecture running an Enterprise Linux system such as RedHat, Rocky or Alma.

The installations are kept in /opt/scls/<flavor> to not interfere with the operating system.

SCLS Flavors for Enterprise Linux 9

  • Debug flavors with reference BLAS/LAPACK

    These flavors are compiled with debug symbols and linked against reference implementations of BLAS and LAPACK. Ideal for development, debugging, and memory leak detection with tools like valgrind.

    • gcc-debug - Developer build with GCC compilers and reference BLAS/LAPACK

  • Production flavors with Intel MKL

    Optimized for high-performance computing with Intel Math Kernel Library (MKL). These flavors require Intel MKL to be installed on your system.

    • gcc-mkl - Production build with GCC compilers and Intel MKL
    • intel-mkl - Intel OneAPI compilers with OpenMPI and Intel MKL

Installation on Enterprise Linux 9

To install a flavor, download the release package and type this into your bash:

sudo dnf install scls-release-2025-1.el9.noarch.rpm
sudo dnf update
sudo dnf install scls-<flavor>

After installation, call the following command to set up your paths:

source /opt/scls/<flavor>/bin/activate

This script will add the */bin directory to your path and set the SCLS environment variable to point to /opt/scls/<flavor>

SCLS Flavor for Amazon Linux 2023

For Amazon Linux, only selected flavors are available. To install, you can type:

sudo yum install scls-release-2025-1.amzn2023.noarch.rpm
sudo yum update
sudo yum install scls-<flavor>

Integer Indexing

All libraries within this repository are compiled with 32-bit integers, ensuring compatibility with a wide range of applications. If you require libraries with 64-bit integers, the compilation files and instructions will be provided in the GitHub repository associated with this collection.

Git Repository

If you want to build your own flavor, feel free to check out the git repository with the build recipes:

git clone https://github.com/cmesse/scls-build-system.git

Known Issues

  • PETSc
    • For the Intel compiler, compilation fails with both CUDA and OpenMP enabled. The Intel version of PETSc is compiled with either CUDA or OpenMP, not both.
  • Strumpack
    • Tests Sparse_HOLDR_mpi_1 and Sparse_mpi_16 fail
  • SuiteSparse
    • Experimental tests of LAGraph fail when using the Intel Compiler
  • Slate
    • The tests for heev fail
